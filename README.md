# Learning Management System (LMS)

Sistema de gerenciamento de cursos desenvolvido com JavaScript (ES6 Modules) e Bootstrap 5.

## Funcionalidades

- Cadastro de categorias, cursos, módulos e aulas.
- Cadastro de alunos e matrícula em cursos.
- Geração de certificados com código de verificação.
- Simulação de checkout via PIX, Cartão e Boleto.
- Armazenamento em memória.

## Estrutura

- **Models:** Entidades do domínio.
- **Services:** Regras de negócio e gerenciamento do estado.
- **UI:** Manipulação da interface e renderização.

## Tecnologias

- HTML5
- CSS3
- JavaScript (ES6 Modules)
- Bootstrap 5
